Setup Guide
✦

Build Your Airtable Base in 20 Minutes

1
Create Airtable account & new base
Go to airtable.com → Sign up → "+ Add a base" → Start from scratch → Name it GlowAssist AI — Med Spa
https://airtable.com/signup
2
Create all 5 tables
Rename Table 1 to Clients, then add: Appointments, Call Logs, Packages & Memberships, Revenue Tracker. Use the + tab at the top.
3
Add all fields — match names exactly
n8n uses exact field names to write data. Any mismatch will cause errors. Copy field names from this template carefully. Field type matters too — set Currency for price fields, not Text.
4
Set up all Treatment options in Appointments
In the Treatment field, add all 12 options: Botox, Dermal Filler, Lip Filler, HydraFacial, VI Chemical Peel, Laser Resurfacing, Laser Hair Removal, Microneedling, Microneedling + PRP, RF Skin Tightening, Consultation, Membership Inquiry.
5
Copy your Base ID for n8n
Your Base ID is in the Airtable URL — it starts with "app". Copy it and replace YOUR_AIRTABLE_BASE_ID in all n8n Airtable nodes.
URL: airtable.com/appXXXXXXXXXX/... ↑ Copy this part (starts with "app")
6
Create 3 Views per table
Grid View (all records), Gallery View (visual client cards), Calendar View on Appointments (see bookings by day). The calendar view is the most impressive thing to show a spa owner!
7
Set up Airtable Automations (bonus)
Add built-in Airtable automation: when Sessions Remaining = 1 in Packages table → email spa owner to upsell the renewal. Another: when Client Status = Lapsed → notify front desk.
8
Share with spa owner — this is your value delivery
Click Share → Invite by email → set role to "Editor". The owner gets their own login to view all data live on any device. Show this during your demo — it's the most impressive moment.
9
Add 4 sample client records before the demo
Manually add 4 realistic fake clients to make the base look professional and lived-in. Use the sample data shown in this template. Include one VIP client with high total spend.
10
Upgrade to Airtable Pro for the spa
At $20/month, Pro unlocks unlimited records and advanced reporting — include this in your monthly fee to the client. Suggest it once they hit 300+ client records.
Med Spa Specific Tips
💉
Track units & refills for injectables
Add a "Units Used" field to Appointments for Botox and filler sessions. This helps the spa track product usage and cost per session — a valuable operational insight.
🎂
Birthday offers drive return visits
Use the Date of Birth field to trigger a birthday SMS automation in n8n: send a 15% off offer 7 days before their birthday. Med spa clients love personalised luxury gestures.
📦
Package balance alert
Set up an Airtable automation: when Sessions Remaining drops to 1, notify the spa team to upsell the renewal during the client's next visit. Never let a package expire silently.
💰
Show revenue saved in your report
Include the Revenue Tracker table in your monthly report to the spa. Showing "$24,380 booked by AI this month" justifies your $400–600/month fee instantly — 40x ROI is hard to argue with.
🌸
Separate VIP client view
Create a filtered view in Clients showing only Status = VIP. Share this view with the spa owner so they can personally follow up with their highest-value clients each month.
📊
Revenue Tracker is your monthly proof
Fill in the Revenue Tracker table manually each month using data from Call Logs. This one table — showing AI booking rate, revenue, and hours saved — is your strongest retention tool as a service provider.
